# Day 1 — Introduction to Data Analysis

## Topics Covered

* What is Data Analysis and why it matters
* The process of Data Analysis
* Data Analyst roles, skills, and career paths
* Understanding structured vs. unstructured data
* The Data Analysis workflow:
  **Collect → Clean → Analyze → Visualize → Report**
* Introduction to technical skills:

  * Excel formulas
  * SQL syntax
  * Power BI interface

## Learning Goal

Build a foundational understanding of Data Analysis, the role of a Data Analyst, the typical data analysis workflow, and the technical tools used throughout the field.

# Day 06 — Excel Conditional Formatting

## What I Learned
Today, I learned how to use Conditional Formatting in Microsoft Excel to highlight data automatically based on specific conditions.

I learned about:
- Highlight Cells Rules
- Greater Than and Less Than rules
- Duplicate Values
- Data Bars
- Color Scales
- Icon Sets

## Practice
I practised applying Conditional Formatting to an employee dataset.

- Selected the Monthly Salary column (F2:F101).
- Created a rule to highlight salaries greater than ₦300,000.
- Used colour formatting to identify values quickly.
- Learned that formatting updates automatically when values change.

## Why It Matters
Conditional Formatting makes data easier to analyse by highlighting important values, identifying patterns, and spotting potential errors.

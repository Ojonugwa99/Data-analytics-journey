# 📊 Day 04 — Excel Functions & Data Analysis

## Topics Covered

* Basic formatting and data presentation
* Aggregate functions:

  * `SUM`
  * `AVERAGE`
  * `COUNTA`
  * `MIN`
  * `MAX`
* Conditional functions:

  * `SUMIF`
  * `AVERAGEIF`
  * `SUMIFS`
  * `AVERAGEIFS`
  * `COUNTIFS`
  * `MAXIFS`
* Applying multiple criteria to employee data
* Formatting salary results as currency
* Organizing and presenting analysis results

## Practical Tasks Completed

* Calculated total salary using `SUM`
* Calculated average salary using `AVERAGE`
* Counted total employees using `COUNTA`
* Calculated total salary for the Sales department using `SUMIF`
* Calculated average salary for the HR department using `AVERAGEIF`
* Calculated total salary for Lagos employees with more than 3 years of experience using `SUMIFS`
* Calculated average salary for female employees in Lagos using `AVERAGEIFS`
* Counted male employees in Lagos using `COUNTIFS`
* Found the maximum salary for employees in the IT department using `MAXIFS`
